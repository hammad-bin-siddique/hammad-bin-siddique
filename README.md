## About Me

I'm a WordPress developer and web designer from **Abbottabad, Pakistan**, with three years of hands-on experience building sites with WordPress, HTML and CSS. Alongside client work I design graphics in Photoshop and Canva. JavaScript is almost done now, and I'm currently learning **React** and **Next.js** on the way to becoming a full stack developer.

I run **[Code Cove](https://instagram.com/cove.code)** — a developer content brand where I share projects, coding content and tech posts.
